    GitHub 처음이면 헷갈리지, 사진처럼 따라해봐!

    GitHub Upload Files 위치 - 단계별로

    1단계: 저장소 만들기

    1. github.com 로그인
    2. 오른쪽 위 + → New repository 클릭
    3. Repository name: kim-stock 입력
    4. Public 체크
    5. Create repository 초록 버튼 클릭

    2단계: Upload Files 버튼 찾기

    저장소 만들면 빈 화면 나오는데:

    Code
    kim-stock 저장소 화면
─────────────────────────────────
Quick setup — if you’ve done this kind of thing before
...
...or create a new repository on the command line

아래에 3개 버튼이 있어:
[Set up in Desktop]  [HTTPS  SSH]  [ ... ]

그 밑에 파란색 링크:
→ "uploading an existing file" 이게 Upload Files야! 
   이 파란 글씨를 클릭하면 돼

    만약 그 링크가 안보이면:

    1. 저장소 화면에서 Add file 버튼 찾기
      • 위치: 오른쪽 위, 초록색 Code 버튼 옆에 있어
      • Add file ▼ 클릭
      • 드롭다운 메뉴에서 Upload files 클릭
    Code
    화면 오른쪽 위:
[ Add file ▼ ] [ Code ▼ ]
     ↓
   ┌─────────────────┐
   │ Create new file │
   │ Upload files    │ ← 이거 클릭!
   └─────────────────┘

    3단계: 파일 올리기

    1. Upload files 화면 나오면:

      • 내가 준 kim-stock-final-v3.zip을 압축 풀어
      • 안에 있는 파일들: index.html, vercel.json, api 폴더, README.md
      • 이 파일들을 마우스로 드래그해서 화면 가운데에 놓기
      • 또는 choose your files 클릭해서 선택

    2. 아래로 스크롤 → Commit changes 초록 버튼 클릭

    4단계: 확인

    • 파일 목록에 index.html, vercel.json, api 폴더 보이면 성공!

    혹시 못 찾겠으면:

    1. 지금 GitHub 저장소 주소가 어떻게 돼? (예: https://github.com/너의아이디/kim-stock)
    2. 주소 알려주면 내가 직접 보고 알려줄게

    또는 화면 스크린샷 찍어 보내줘, 어디서 막혔는지 화살표로 표시해줄게!

    새로 배포한 url 알려줄께 한국 주식 가격과 수급 데이터등 직접 보고 알려줘
    오늘

    좋아! 새 주소 알려줘.

    주소 주면 내가 바로:

    1. 한국 주식 현재가가 네이버 실시간이랑 일치하는지
    2. 수급 데이터 (외국인/기관/개인) 제대로 나오는지
    3. Finnhub 미국 선물 실시간 연결 상태
    4. F12 콘솔에 CORS 에러 없는지

    다 직접 들어가서 확인하고 알려줄게!

    URL 붙여넣어줘 👇

    https://kim-stock-liart.vercel.app/
    오늘
    생각 표시

    아, Vercel 주소가 보안 정책 때문에 내 브라우저 도구로는 직접 못 열어보네! (api도 차단됨)

    그래도 너가 직접 확인하면 10초 만에 알 수 있어. 이렇게 해줘:

    너가 직접 체크하는 방법 (1분)

    1. 사이트 접속
    https://kim-stock-liart.vercel.app/ 들어가서

    2. F12 → Console 탭 열기
    아래 로그가 뜨는지 확인해줘:

    성공이면 이렇게 떠야 해:

    Code
    [KR] /api/naver?code=123010 호출
[KR] 응답: { closePrice: 1320, ... } 또는 totalInfos
[KR] 실시간 ● 아이윈플러스 ₩1,320
[Finnhub] 실시간 ● SPY $766.48

    실패면 이렇게 뜸:

    Code
    [KR] /api/naver?code=... 404
또는
Failed to fetch /api/naver

    3. 내게 알려줄 것 3가지

    1. Console 로그 복사해서 붙여넣기 (한국 주식 부분)
    2. 화면에서 한국 주식 가격 - 예: 아이윈플러스 얼마라고 뜨는지
    3. 네이버 증권에서 아이윈플러스 검색했을 때 실제 가격

    이 3개 알려주면 내가 가격이 맞는지, 수급 데이터 연결도 정상인지 바로 판단해서 고쳐줄게!
