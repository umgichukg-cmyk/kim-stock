# 김가네 주식 v2

전날 미국 시장에서 크게 움직인 테마를 찾고, 그 테마에 연결된 한국 종목을 **실제 지표로만** 100점 만점 점수화하는 웹앱입니다.

- 한국 시장 장중 흐름 탭(첫 화면): 친구 말투 브리핑(지수 흐름·수급·분위기·업종·테마·눈에 띄는 종목·주요 뉴스 2개, 실시간 숫자로만 자동 작성), 코스피·코스닥·코스피200 오늘 1분봉 흐름, 투자자별 순매수(장중 잠정), 오른·내린 종목 수와 상한가·하한가, 지금 상승률·하락률·거래대금 상위(종합 점수 함께), 업종·테마 등락(누르면 대표 종목 지금 시세) · 장중에는 1분마다 자동 갱신
- 미국 테마 브리핑: 테마별 미국 대표 종목의 전일(장 마감된 마지막 거래일) 평균 등락 → 상승률 높은 순서 (오른 테마만 점수화)
- 한국 종목 점수: 기술 45(추세·RSI·거래대금) + 수급 45(외국인·기관 순매수·연속성) + 기본 10(성장성·수익성·가치·재무 안정성)
- 종목 상세: 분봉(최근 5거래일 정규장, 1·5·15·60분)·일봉·주봉(약 10년)·월봉(2000년부터) 캔들 + 5/20/60 이동평균, 일봉에는 20일 VWAP, 점수 근거, 관련 뉴스(제목·언론사·시각, 원문 링크), 투자자별 5~30일 순매수, 재무 요약(연간 실적·추정치·목표주가)
- 종목명 또는 종목코드로 검색해서 아무 종목이나 분석 (입력하면 추천 목록 표시)
- 한국주식 상위 30 탭: 마지막으로 끝난 장 기준, 코스피·코스닥 전체 종목 중 점수 상위 30 (매일 저녁 자동 계산)
- 상한가·하한가 탭: 전일 종가 기준 상한가·하한가로 마감한 보통주 (±29% 이상이면서 종가 = 고가/저가), 종합 점수 함께
- 공모주 청약 탭: 네이버 공모주 정보로 청약 일정(청약 중·D-n·상장 대기, 공모가, 기관 경쟁률, 상장 예정일, 주관사, 기업개요 자료), 참고용 청약 점수(기관 경쟁률 40·공모가 위치 25·실적 20·공모 규모 15, 검증 전 규칙), 상장 준비 중인 기업 목록
- 미국 시장 브리핑 탭: 전일(장 마감된 마지막 거래일) 미국 지수·금리·달러·원자재·업종·빅테크 등락, 숫자로 자동 작성한 요약, 관련 뉴스
- 한국 시장 브리핑 탭: 전일(장 마감된 마지막 거래일) 코스피·코스닥·코스피200, 투자자별 순매수, 오른/내린 종목 수, 업종 등락, 상승·하락률·거래대금 상위 종목, 자동 요약, 주요 뉴스
- 한국 테마 브리핑 탭: 전일 종가 기준 네이버 테마 전체(오른·내린 테마, 이름 검색), 테마를 누르면 관련 종목(등락률·시가총액·종합 점수), 테마별 연속 상승·하락 일수, 전환(전날과 반대 방향)·NEW(새로 생긴 테마) 배지
- 시장 지표: 코스피, 코스닥, 원/달러, 비트코인, 국제유가(WTI), 다우존스, 나스닥100, 필라델피아 반도체, S&P500·나스닥 선물 · 누르면 1일~5년 상세 차트(한국 시간 기준)

데이터를 못 받아오면 가짜 값으로 채우지 않고 "불러오지 못함" / "계산 불가"로 보여줍니다.
API 키가 필요 없습니다 (네이버 증권 + Yahoo Finance 공개 데이터).

> 투자 참고용이며 매수·매도 권유가 아닙니다. 시세는 지연될 수 있습니다.

Node.js 20 이상이 필요합니다.


## 전체 종목 점수 계산 (한국주식 상위 30 탭)

- GitHub Actions가 평일 한국 시간 저녁 7시에 `scripts/scan-market.js`를 실행합니다.
- 코스피·코스닥 일반 주식 전체에서 ETF·ETN·우선주·스팩·거래정지와 20일 평균 거래대금 10억 원 미만을 빼고 점수를 계산합니다.
- 카드의 "연속 N일"은 거래일 기준(주말·휴장일 제외)으로 상위 30에 연속해서 든 날 수입니다. 날짜별 순위는 `history.json`에 60거래일치 보관합니다. 자동 계산이 빠진 거래일이 있으면 그 날에서 연속이 끊깁니다.
- 같은 실행에서 한국 시장 브리핑(`kr-briefing.json`)도 그날 마감 기준으로 저장합니다. 장중에 실행하면 업종 등락은 빠집니다.
- 한국 테마(`kr-themes.json`)도 같은 실행에서 저장합니다 (장중 실행이면 이전 결과 유지). 테마별 날짜별 등락률은 `theme-history.json`에 60거래일치 보관하고, 연속 상승·하락 일수를 계산합니다. 기록이 없는 과거 30거래일은 관련 종목 일봉 평균으로 채웁니다. 테마를 처음 본 날은 `theme-catalog.json`에 기록해, 새로 생긴 테마를 5거래일 동안 NEW로 표시합니다 (첫 기록 때 있던 테마는 기존으로 등록).
- 결과(`top30.json`, `history.json`, `kr-briefing.json`, `kr-themes.json`)는 `data` 브랜치에 덮어써서 저장하고, 화면은 `/api/top30`으로 읽습니다. main에는 커밋이 쌓이지 않습니다.
- 바로 다시 계산하려면 GitHub 저장소 → Actions → "전체 종목 점수 계산" → Run workflow
- 내 컴퓨터에서: `node scripts/scan-market.js` (결과는 `data/top30.json`, 로컬 서버가 이 파일을 먼저 읽음)

## 백테스트

"전일 미국장에서 오른 테마의 한국 종목을 다음 날 시가에 매수"한 결과를 과거 데이터로 확인합니다.

```bash
node scripts/backtest.js --from 2025-11-03 --to 2026-10-30 --cost 0.25 --top 4
```

- 그날 아침 기준으로 전날까지의 일봉·수급만 써서 점수를 다시 계산합니다 (기본 점수는 과거 데이터가 없어 제외)
- 결과 요약은 화면에, 거래 내역은 `backtest-results/`에 CSV로 저장합니다 (git에는 올리지 않음)
- 받아온 데이터는 `.cache/backtest/`에 저장해 다시 실행할 때 재사용합니다

### 전략 비교 백테스트

코스피·코스닥 보통주 전체(그 시점 20일 평균 거래대금 10억 원 이상)로 연구에서 자주 언급되는 전략을 비교합니다.

```bash
node scripts/backtest-strategies.js --from 2025-01-02 --n 20 --cost 0.25
```

- ① 52주 신고가 근접 ② 저변동성(60일) ③ 모멘텀(12-1): 매월 첫 거래일 시가에 상위 N종목을 같은 금액씩 바꿔 담기
- ④ 밤사이 보유: 매일 종가 매수 → 다음 날 시가 매도
- 비교: 코스피·코스닥 지수 보유, 대상 종목 전체 같은 금액씩
- 누적·연환산 수익률, 최대 낙폭, 전반기/후반기 수익률, 월 승률 출력
- 한계: 지금 상장된 종목만 써서 상장폐지 종목이 빠짐 (결과가 실제보다 좋게 나올 수 있음)

## 로그인 · 관심 종목 · 메모 (Supabase)

- 가족 계정으로 로그인하면 종목 상세의 **☆ 관심** 버튼과 **내 메모**를 쓸 수 있고, **관심 종목** 탭에 모아 볼 수 있어요.
- 저장한 내용은 본인만 볼 수 있어요 (데이터베이스 보안 규칙 RLS).
- 화면 코드의 Supabase 키는 공개용(publishable) 키예요. secret 키는 코드에 넣지 않아요.
- 처음 설정: Supabase SQL Editor에서 `supabase/schema.sql` 실행 → Authentication에서 새 가입 막기 → 가족 계정 직접 추가.
- Supabase 라이브러리는 로그인 기록이 있거나 로그인 창을 열 때만 불러와요.

## 점수 기준

| 구분 | 항목 | 배점 | 계산 |
|---|---|---|---|
| 기술 | 추세 | 15 | 주가>20일선 5, 5일선>20일선 5, 20일선>60일선 5 |
| 기술 | 모멘텀 | 15 | RSI(14) 50~70 15점, 40~50 9점, 70~80 8점, 30~40 4점, 80 이상 3점, 30 미만 2점 |
| 기술 | 거래대금 | 15 | 최근 5일 평균 ÷ 직전 20일 평균: 200%↑ 15, 150%↑ 12, 120%↑ 9, 100%↑ 6, 70%↑ 3 |
| 수급 | 외국인 | 18 | 최근 5일 순매수 금액 ÷ 같은 기간 거래대금: 10%↑ 만점, 5%↑ 80%, 2%↑ 60%, 0 초과 40%, -2% 초과 20% |
| 수급 | 기관 | 18 | 외국인과 같은 방식 |
| 수급 | 매수 연속성 | 9 | 최근 5일 중 외국인+기관 합계 순매수인 날의 비율 |
| 기본 | 성장성 | 3 | 최근 연도 매출 증가 1, 영업이익 증가 1, 올해 추정 영업이익이 최근 실적보다 높으면 1 |
| 기본 | 수익성 | 3 | 최근 연도 ROE 10%↑ 3, 5%↑ 2, 0 초과 1 |
| 기본 | 가치 | 2 | PER 15배 이하 2, 30배 이하 1, 그 이상·적자 0 |
| 기본 | 재무 안정성 | 2 | 부채비율 100% 이하 2, 200% 이하 1 (증권·은행 등 금융업은 구조상 낮게 나옵니다) |

순매수 금액은 네이버가 주는 순매수 **수량 × 그날 종가**로 추정합니다.
데이터가 부족한 항목은 빼고 나머지로 100점 환산합니다 (예: ETF는 재무제표가 없어 기본 점수를 제외).
증권사 목표주가와 투자의견은 상세 화면에 참고로만 보여주고 점수에는 넣지 않습니다.

## v1에서 바뀐 점

- Meta AI가 만든 압축 번들(`index.html` 344KB)을 읽고 고칠 수 있는 소스로 새로 작성
- 무작위 값·고정 문구로 채우던 가짜 데이터(테마 변동성, 선물 차트, RSI·수급 설명)를 모두 제거
- 코드에 박혀 있던 Finnhub API 키 제거, 키움·Finnhub 의존성 제거
- 테마/종목을 `config/themes.js` 한 곳에서 관리
