# 김가네 주식 v2

전날 미국 시장에서 크게 움직인 테마를 찾고, 그 테마에 연결된 한국 종목을 **실제 지표로만** 100점 만점 점수화하는 웹앱입니다.

- 미국 테마 흐름: 테마별 미국 대표 종목의 전일(장 마감된 마지막 거래일) 평균 등락 → 상승률 높은 순서 (오른 테마만 점수화)
- 한국 종목 점수: 기술 45(추세·RSI·거래대금) + 수급 45(외국인·기관 순매수·연속성) + 기본 10(성장성·수익성·가치·재무 안정성)
- 종목 상세: 일봉 캔들 + 5/20/60일선 + 20일 VWAP, 점수 근거, 투자자별 20일 순매수, 재무 요약(연간 실적·추정치·목표주가)
- 아무 종목코드나 검색해서 분석 가능
- 시장 지표: 코스피, 코스닥, 원/달러, 비트코인, 국제유가(WTI), 다우존스, 나스닥100, 필라델피아 반도체, S&P500·나스닥 선물

데이터를 못 받아오면 가짜 값으로 채우지 않고 "불러오지 못함" / "계산 불가"로 보여줍니다.
API 키가 필요 없습니다 (네이버 증권 + Yahoo Finance 공개 데이터).

> 투자 참고용이며 매수·매도 권유가 아닙니다. 시세는 지연될 수 있습니다.

## 폴더 구조

```
index.html          화면 뼈대
assets/style.css    디자인 (라이트/다크 자동)
assets/app.js       화면 동작
config/themes.js    ★ 테마·종목·시장지표 설정 - 종목을 바꾸려면 이 파일만 수정
api/picks.js        GET /api/picks   테마 순위 + 추천 종목 점수
api/stock.js        GET /api/stock?code=005930   종목 상세
api/market.js       GET /api/market  지수·선물·환율
api/_lib/           데이터 수집(naver, yahoo)과 점수 계산(score)
scripts/dev-server.js  내 컴퓨터에서 실행하는 서버
```

## 내 컴퓨터에서 실행

Node.js 20 이상이 필요합니다.

```bash
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 점수 기준

| 구분 | 항목 | 배점 | 계산 |
|---|---|---|---|
| 기술 | 추세 | 15 | 주가>20일선 5, 5일선>20일선 5, 20일선>60일선 5 |
| 기술 | 모멘텀 | 15 | RSI(14) 50~70 15점, 40~50 9점, 70~80 8점, 30~40 4점, 80 이상 3점, 30 미만 2점 |
| 기술 | 거래대금 | 15 | 최근 5일 평균 ÷ 직전 20일 평균: 200%↑ 15, 150%↑ 12, 120%↑ 9, 100%↑ 6, 70%↑ 3 |
| 수급 | 외국인 | 18 | 최근 5일 순매수 금액 ÷ 같은 기간 거래대금: 10%↑ 만점, 5%↑ 80%, 2%↑ 60%, 0 초과 40%, -2% 초과 20% |
| 수급 | 기관 | 18 | 외국인과 같은 방식 |
| 수급 | 매수 연속성 | 9 | 최근 5일 중 외국인+기관 합계 순매수인 날의 비율 |
| 기본 | 성장성 | 3 | 최근 연도 매출 증가 1, 영업이익 증가 1, 올해 추정 영업이익이 최근 실적보다 높으면 1 |
| 기본 | 수익성 | 3 | 최근 연도 ROE 10%↑ 3, 5%↑ 2, 0 초과 1 |
| 기본 | 가치 | 2 | PER 15배 이하 2, 30배 이하 1, 그 이상·적자 0 |
| 기본 | 재무 안정성 | 2 | 부채비율 100% 이하 2, 200% 이하 1 (증권·은행 등 금융업은 구조상 낮게 나옵니다) |

순매수 금액은 네이버가 주는 순매수 **수량 × 그날 종가**로 추정합니다.
데이터가 부족한 항목은 빼고 나머지로 100점 환산합니다 (예: ETF는 재무제표가 없어 기본 점수를 제외).
증권사 목표주가와 투자의견은 상세 화면에 참고로만 보여주고 점수에는 넣지 않습니다.

- 테마/종목을 `config/themes.js` 한 곳에서 관리
