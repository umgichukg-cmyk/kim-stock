## 1. 자본시장법 — 유사투자자문업 / 투자자문업

**지금 상태**
- 가족 4명만 무료로 씀. 영업(대가)이 없으니 지금은 금융투자업·유사투자자문업 문제가 생기지 않는 구조.
- 화면 기능: 종목 100점 점수, 상위 30, 조건 검색 신호(날짜별 종목 + '이후 최고점 상승률'), 상한가 이유, 공모주 청약 점수, 브리핑. 1:1 상담·채팅 없음. 자동매매 없음(키움은 조회만).

**확인한 사실**
- 유사투자자문업자는 **단방향 채널로 불특정 다수에게 개별성 없는 조언만** 할 수 있음. SNS·오픈채팅방 등 **양방향 채널로 유료 회원제 영업을 하면 투자자문업자로 규율**되고, 위반하면 미등록 투자자문업으로 **3년 이하 징역 또는 1억원 이하 벌금**. 2024-08-14 시행 개정. ([금융위원회 보도자료](https://www.fsc.go.kr/no010101/82887))
- **1:1 투자자문은 금융위에 등록한 투자자문업자만** 가능. (같은 자료)
- 유사투자자문업자는 ① 자신이 유사투자자문업자이고 개별 상담을 할 수 없다는 점 ② 원금손실 가능성을 고지해야 하고, 손실보전·이익보장 약정 금지, 금융소비자보호법 수준의 광고 규제 적용. 신고 유효기간 5년, 방문판매법·전자상거래법 위반자도 신고 불수리. (같은 자료)
- 신고 전 금융투자협회 교육(8시간) 이수가 필요하다는 정부 자료가 있음. ([유사투자자문업자 제도개선방안, 2021](https://www.smallake.kr/wp-content/uploads/2021/06/유사투자자문업자-제도개선방안-full-vf.pdf) — 현행 요건은 금감원에서 재확인)
- 금감원은 유료 구독자에게 특정 종목을 추천하면서 신고하지 않은 사례, 신고만 하고 **등록 없이 자동매매 프로그램을 판 사례(미등록 투자일임)**를 적발함. ([MTN 2026-09](https://news.mtn.co.kr/news-detail/2026091011344567777), [정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=148935062))
- 신고 여부는 금감원 파인(fine.fss.or.kr)에서 누구나 조회 가능.
- 법 조문 번호(제6조·제7조·제101조 이하, 벌칙 조문)는 법제처 페이지가 스크립트로만 열려 이번에 원문을 읽지 못함 → 변호사 검토 때 함께 확인.

**판매 전에 할 일**
1. ⚖ 변호사 확인 필요: "알고리즘이 계산한 점수·순위·신호를 유료 구독자 모두에게 똑같이 보여주는 웹앱"이 유사투자자문업 신고 대상인지, 신고만으로 충분한지(개별성 없음·단방향 유지).
2. 대상이면 대표 명의(또는 법인)로 협회 교육 → 금융위(금감원 접수) 신고 → 신고번호를 화면·약관에 표시.
3. **넣지 말 것**: 채팅·댓글 문답·1:1 상담·카톡 오픈채팅, 사용자 보유 종목 맞춤 조언, 자동 주문. (넣는 순간 투자자문업·투자일임업 등록 문제)
4. 화면 고지 문구 추가: '유사투자자문업자이며 개별 상담을 하지 않음', '원금손실 가능', '투자 판단과 책임은 본인'.

**막히면 대안**
- 무료 공개(광고·후원 없이) → 대가가 없으면 금융투자업 영업 판단이 달라질 수 있음. ⚖ 확인 필요.
- 종목 이름이 나오는 신호·순위는 빼고 '시장 브리핑·차트 도구'만 판매 → 자문 성격을 줄임. ⚖ 확인 필요.

**결론: 변호사 확인 필요** (판매 전 필수)

## 2. 자료 출처 — 네이버 증권 · Yahoo · 거래소 시세 · 뉴스

**지금 상태**
- API 키 없이 서버가 네이버 증권(`m.stock.naver.com`, `api.stock.naver.com`, 뉴스)과 Yahoo Finance 공개 주소를 직접 읽음. 저녁 계산은 GitHub Actions가 전 종목을 돌며 수집.
- 화면 하단에 '데이터: 네이버 증권, Yahoo Finance' 표시.

**확인한 사실**
- **네이버 증권 화면 하단**: 제공 정보는 오류·지연이 있을 수 있고 네이버파이낸셜은 투자결과에 책임지지 않으며, **"게시된 정보는 무단으로 배포할 수 없습니다"**. (m.stock.naver.com, 2026-11-26 확인)
- **네이버 이용약관**(주의사항): 네이버의 **사전 허락 없이 자동화된 수단(매크로, 봇, 스파이더, 스크래퍼 등)으로** 게시물 등을 수집하거나 서비스 취지에 맞지 않게 이용하는 행위 금지. ([네이버 이용약관](https://policy.naver.com/rules/service.html))
- **거래소 시세 원천**: 코스콤 정보이용정책상 정보를 남에게 제공하는 자는 '정보사업자'로 코스콤과 계약해야 하고, **사전승인 없이 가입자에게 데이터피드로 정보(지연정보 포함)를 제공할 수 없음**. 이용 내역 월별 보고 의무. ([KRX 정보이용정책](https://data.krx.co.kr/inc/datasale/Market%20Data%20Usage%20Polices_ko.pdf), 2016년판 — 최신판 확인 필요)
- **Yahoo 약관** 2(d): 사전 허가 없는 자동 수집, 서비스 자료로 데이터 피드 만들기 금지. 2(e)·2(h): 명시적 서면 허가 없는 상업 목적 이용·배포 금지. ([Yahoo Terms](https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html))
- **뉴스**: 지금은 제목·언론사·시각·원문 링크만 보여줌(본문 복제 없음). 제목·링크만이면 위험이 낮은 편이지만, 네이버 뉴스에서 자동 수집해 유료로 보여주는 것은 위 네이버 약관 문제와 겹침. ⚖ 확인 필요.

**판매 전에 할 일**
1. 유료판에서는 네이버·Yahoo 직접 수집을 **쓰지 않는 것을 원칙**으로 함(가족판은 그대로 둘 수 있으나 그것도 약관상 회색).
2. 자료를 기능별로 공식 경로로 바꾸는 표를 만든다(아래 대안). 바꿀 수 없는 기능은 판매판에서 뺀다.
3. 화면 출처 표기를 새 자료원 계약 조건대로 바꾼다.

**막히면 대안 (확인 필요 표시는 이용 조건을 아직 읽지 않았다는 뜻)**
| 필요한 것 | 후보 |
|---|---|
| 일별 시세(종가·거래량) | 공공데이터포털 '금융위원회_주식시세정보'(하루 지연, 공공누리 조건 확인 필요), 코스콤·KRX 정보이용계약(유료) |
| 외국인·기관 수급, 장중 시세, 테마 | 코스콤 정보사업자 계약 또는 계약된 데이터 업체 유료 API(비용 확인 필요). 공짜 공식 경로는 찾지 못함 |
| 재무·공시 | 금감원 DART Open API(무료, 상업 이용 조건 확인 필요) |
| 미국 지수·환율 | 유료 시세 API(상업 라이선스 포함 요금제) |
| 뉴스 | 언론사·뉴스 API 제휴, 또는 판매판에서 뉴스 제외 |
- 수급(외국인·기관)이 점수의 45점이라, 이게 공식 경로로 안 되면 점수 체계 자체를 바꿔야 함 → 판매 여부를 가르는 핵심 비용.

**결론: 고쳐서 진행(자료원 교체) + 계약 조건은 변호사 확인 필요**

## 3. 키움 계좌 연결

**지금 상태**
- `kiwoom-relay/` 중계 서버(고정 IP)가 젠틀맨 본인 키움 계좌 잔고만 조회. OWNER_EMAIL 한 계정, 운영 주소 두 곳만 허용. 주문 기능 없음.

**확인한 사실**
- 키움 REST API 홈페이지(openapi.kiwoom.com)의 서비스 이용안내·약관 본문은 이번에 열지 못함(스크립트 링크). 본인 계좌 전용인지, 제3자 서비스 제공 금지인지 **미확인**.
- 일반 원칙: 다른 사람의 증권 계좌·잔고를 우리 서버가 받으면 개인(신용)정보를 처리하게 되고, 금감원은 등록 없이 자동매매 프로그램을 판 업체를 미등록 투자일임으로 적발함(1절 출처).

**판매 전에 할 일**
1. **판매판에서는 키움 계좌 기능을 뺀다**(코드에서 판매판 빌드 때 계좌 칸·`account.js` 계좌 부분 제외). 가족판에만 남김.
2. 중계 서버는 판매판 주소를 허용 목록에 넣지 않는다.

**막히면 대안**: 사용자 계좌 연동이 꼭 필요하면 증권사 제휴(공식 계약) 또는 마이데이터 사업자 경로 — 규제·비용이 커서 지금 규모에서는 권하지 않음.

**결론: 고쳐서 진행(판매판에서 제외)**

## 4. 광고·화면 표시 (백테스트·수익률·안내 문구)

**지금 상태**
- 화면 일부에 '매수·매도 권유가 아니에요', '청약 점수(참고용)', '목표주가는 참고용' 있음. 전체 공통 '투자 참고용·원금손실' 안내는 README에만 있고 화면 하단에는 없음.
- 조건 검색에 **'신호 뒤 최고점 상승률'**(신호 다음 날부터 장중 최고가 ÷ 신호 날 종가)을 보여줌 → 실제로 그 값에 팔 수 없는 **미실현·최고점 기준 수익률**.
- 백테스트 스크립트·결과는 화면에 없음(내부용). README에 '상장폐지 종목이 빠져 결과가 좋게 나올 수 있음' 한계 적어 둠.
- 화면 하단에 **가족 4명 실명**이 공개 페이지에 노출돼 있음(가족판 문제이기도 함).

**확인한 사실**
- 유사투자자문업 광고 금지 유형: 금융회사로 오인하게 하는 표시, **허위 또는 미실현 수익률 제시, 수익이 좋았던 기간만 보여주기**, 불확실한 사항을 단정하는 표현. (1절 금융위 자료)

**판매 전에 할 일**
1. '최고점 상승률'은 판매판에서 빼거나, 종가 기준 실제 수익률(+하락도 함께, 전체 기간 평균)로 바꾸고 '과거 결과는 미래를 보장하지 않음'을 붙임.
2. 백테스트·적중률을 홍보에 쓰지 않는다(쓰려면 전체 기간·비용·생존편향 포함, ⚖ 확인 후).
3. 모든 화면 하단 공통 고지: 투자 참고용, 매매 권유 아님, 원금손실 가능, 시세 지연 가능, (신고 후) 유사투자자문업 신고번호·개별 상담 불가.
4. '추천', '급등 예상', '수익 보장' 같은 말은 화면·홍보 어디에도 쓰지 않는다(회사 홍보 원칙과 같음).
5. 가족 실명 문구는 판매판에서 빼고, 가족판도 이름 노출을 줄이는 쪽 권함(젠틀맨 결정).

**결론: 고쳐서 진행** (문구 최종본은 변호사 검토 때 함께)

## 6. 판매 여부를 정하기 위한 순서 (권하는 순서)

1. 변호사 상담 1회: 1절(신고 대상·범위) + 2절(자료 계약) + 4절 문구를 한 번에 묻기. 질문지는 메이커가 준비할 수 있음.
2. 자료 비용 견적: 코스콤/데이터 업체 유료 API(수급 포함)의 월 비용 — 외부 문의라 **젠틀맨 허락 뒤** 진행.
3. 1·2 결과로 '판매판 기능 목록'(가능/수정/제외) 확정 → 그다음 디자인 시안을 판매판 기준으로 맞춤.
4. 디자인 시안은 그 사이 미리보기에서만 진행(기능은 그대로, 운영 반영은 젠틀맨 컨펌 뒤).
