## 1. 자본시장법 — 유사투자자문업 (젠틀맨: **이미 신고됨**, 11/26)

**지금 상태**
- 젠틀맨은 유사투자자문업 신고가 되어 있음(11/26 김실장 전달). 신고번호·상호·신고일은 이 PC 폴더와 Gmail에서 찾지 못함(다운로드 폴더에 금감원 '신고 및 보고 매뉴얼'·'갱신신고서식'(2024-10-31판, 2025-06 내려받음)만 있음, 작성본 없음).
- 앱은 가족 4명 무료 사용. 1:1 상담·채팅 없음, 자동매매 없음(키움은 조회만).

**확인한 사실** (출처: 금융감독원 「유사투자자문업자 신고 및 보고 매뉴얼」 2024-10-31 개정·시행판, 붙임 법령 포함 — 이하 '금감원 매뉴얼'. 같은 내용 [금융위 보도자료](https://www.fsc.go.kr/no010101/82887))
- 정의(자본시장법 §101①, §7③, 시행령 §102): 대가를 받고 간행물·통신물·방송 등으로 **개별성 없는 조언**. 1:1 투자자문 금지, **양방향 소통 금지**.
- §7③ 단서: 온라인에서 대가를 낸 고객과 **의견을 교환할 수 있으면 투자자문업**으로 봄 → 유료 고객에게 댓글창·대화창 등 양방향 소통을 원천 차단해야 함. 위반(미등록 투자자문·일임) 3년 이하 징역 또는 1억원 이하 벌금.
- 신고 유효기간(§101⑥): 수리일부터 **5년**. 갱신은 **만료 3개월 전~1개월 전** 금감원(자산운용감독국 자문·신탁감독팀)에 갱신신고(시행령 §102②). 기간을 넘기면 갱신 불가 → 신규신고, 그 사이 영업은 미신고 영업(1년 이하 징역 또는 3천만원 이하 벌금).
- 교육(§101⑦): 신규·갱신신고일 **전 1년 이내**에 금융투자협회 금융투자교육원(kifin.or.kr) '유사투자자문업 신고 사전교육' 이수증 필요. 매뉴얼에 매년 받는 '보수교육'은 없고, 갱신 때마다 다시 이수하는 방식.
- 변경 보고(§101②): 폐지, **명칭·소재지 변경, 대표자·임원 변경** 시 2주 이내 보고(위반 시 과태료).
- 직권말소(§101⑨): 세무서 폐업신고·사업자등록 말소, 방문판매법·전자상거래법 시정조치 불이행, 5년 안 과태료 재위반 등.
- 표시·광고 금지(§101의2②, 시행령 §102의2): 금융회사로 오인, 손실보전·이익보장 오인, **수익률을 사실과 다르게 표시하거나 실현되지 않은 수익률 제시**(목표 수익률, 종목 수익률 합산 등), 근거 없는 비교 우위, **좋은 기간만 보여주기**, 불확실한 것 단정. 과거 수익률은 실증 가능해야 하고 이익 난 종목만 골라 보이면 안 됨. 위반 1억원 이하 과태료.
- 표시·광고에 꼭 넣을 것(§101의3): ① 개별적인 투자 상담과 자금운용이 불가능 ② 원금 손실 가능, 손실은 투자자에게 귀속 ③ 정식 금융투자업자가 아닌 유사투자자문업자. 위반 1억원 이하 과태료.
- 그 밖에: 손실보전·이익보장 약속 금지(§55 준용, 3년·1억), 매매·중개·자금 보관·선행매매 금지, 상호에 '금융투자·증권·자산운용' 금지, **'금융위원회 정식 등록' 같은 표현 금지**(신고일 뿐), 환불 규정은 결제 때 따로 눈에 띄게 안내(약관규제법), 회원을 모아 특정 종목에 몰아가는 행위 금지(불공정거래).

**판매 전에 할 일**
1. **신고 사업자·상호 확인**: 신고증의 상호·사업자번호·대표자가 판매할 사업자(로얄서번트)와 같은지. 다르면 판매 사업자로 새로 신고하거나 기존 신고 사업자로 판매(⚖ 확인). 대표자·명칭·소재지가 바뀐 게 있으면 2주 보고 여부 확인.
2. **유효기간 확인**: 파인(fine.fss.or.kr) 유사투자자문업자 신고현황에서 신고일 확인 → 만료일 계산 → 갱신 창(3개월 전~1개월 전)을 회사 일정에 등록. 갱신 전 1년 안에 사전교육 재이수. 2025-06에 갱신서식을 내려받은 기록이 있어 이미 갱신했는지도 확인.
3. **신고서의 정보제공 수단**: 신고(갱신) 때 낸 사업계획서에 '홈페이지/앱' 수단이 들어 있는지. 없으면 추가 보고·변경 필요한지 ⚖ 확인.
4. **화면에서 막을 것**: 유료 회원 대상 댓글·채팅·문의 게시판의 투자 문답, 카톡 오픈채팅, 1:1 상담, 사용자 보유 종목 맞춤 조언, 자동 주문. 고객 문의는 결제·오류 같은 비투자 문의만 받는 창구로 분리(투자 질문엔 답하지 않는다는 안내).
5. **화면·광고·약관 공통 고지(§101의3 세 가지)**: 모든 화면 하단, 판매 페이지, 홍보 글, 약관에 넣음. 문안(초안, 변호사 확인 전):
   > 김가네 주식은 정식 금융투자업자가 아닌 유사투자자문업자(신고번호 ○○)가 제공하는 정보 서비스입니다. 개별적인 투자 상담과 자금 운용은 하지 않습니다. 투자에는 원금 손실이 생길 수 있으며 그 손실은 투자자 본인에게 귀속됩니다.
6. **지울 표현**: '최고점 상승률'(미실현 수익률), 종목 수익률 합산·평균을 성과처럼 보이는 것, '수익', '보장', '확실', '급등 예정', '금융위 등록'. 점수는 '계산 결과'로만 표기.
7. 환불 규정을 결제 화면에 따로 표시(4·5절).

**결론: 고쳐서 진행** — 신고 사업자 일치·유효기간·제공 수단은 변호사(또는 금감원 안내) 확인 필요

## 2. 자료 출처 — 네이버 증권 · Yahoo · 거래소 시세 · 뉴스

**지금 상태**
- API 키 없이 서버가 네이버 증권(`m.stock.naver.com`, `api.stock.naver.com`, 뉴스)과 Yahoo Finance 공개 주소를 직접 읽음. 저녁 계산은 GitHub Actions가 전 종목을 돌며 수집.
- 화면 하단에 '데이터: 네이버 증권, Yahoo Finance' 표시.

**확인한 사실**
- **네이버 증권 화면 하단**: 제공 정보는 오류·지연이 있을 수 있고 네이버파이낸셜은 투자결과에 책임지지 않으며, **"게시된 정보는 무단으로 배포할 수 없습니다"**. (m.stock.naver.com, 2026-11-26 확인)
- **네이버 이용약관**(주의사항): 네이버의 **사전 허락 없이 자동화된 수단(매크로, 봇, 스파이더, 스크래퍼 등)으로** 게시물 등을 수집하거나 서비스 취지에 맞지 않게 이용하는 행위 금지. ([네이버 이용약관](https://policy.naver.com/rules/service.html))
- **거래소 시세 원천**: 코스콤 정보이용정책상 정보를 남에게 제공하는 자는 '정보사업자'로 코스콤과 계약해야 하고, **사전승인 없이 가입자에게 데이터피드로 정보(지연정보 포함)를 제공할 수 없음**. 이용 내역 월별 보고 의무. ([KRX 정보이용정책](https://data.krx.co.kr/inc/datasale/Market%20Data%20Usage%20Polices_ko.pdf), 2016년판 — 최신판 확인 필요)
- **Yahoo 약관** 2(d): 사전 허가 없는 자동 수집, 서비스 자료로 데이터 피드 만들기 금지. 2(e)·2(h): 명시적 서면 허가 없는 상업 목적 이용·배포 금지. ([Yahoo Terms](https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html))
- **뉴스**: 지금은 제목·언론사·시각·원문 링크만 보여줌(본문 복제 없음). 제목·링크만이면 위험이 낮은 편이지만, 네이버 뉴스에서 자동 수집해 유료로 보여주는 것은 위 네이버 약관 문제와 겹침. ⚖ 확인 필요.

**판매 전에 할 일**
1. 유료판에서는 네이버·Yahoo 직접 수집을 **쓰지 않는 것을 원칙**으로 함(가족판은 그대로 둘 수 있으나 그것도 약관상 회색).
2. 자료를 기능별로 공식 경로로 바꾸는 표를 만든다(아래 대안). 바꿀 수 없는 기능은 판매판에서 뺀다.
3. 화면 출처 표기를 새 자료원 계약 조건대로 바꾼다.

## 3. 키움 계좌 연결

**지금 상태**
- `kiwoom-relay/` 중계 서버(고정 IP)가 젠틀맨 본인 키움 계좌 잔고만 조회. OWNER_EMAIL 한 계정, 운영 주소 두 곳만 허용. 주문 기능 없음.

**확인한 사실**
- 키움 REST API 홈페이지(openapi.kiwoom.com)의 서비스 이용안내·약관 본문은 이번에 열지 못함(스크립트 링크). 본인 계좌 전용인지, 제3자 서비스 제공 금지인지 **미확인**.
- 일반 원칙: 다른 사람의 증권 계좌·잔고를 우리 서버가 받으면 개인(신용)정보를 처리하게 되고, 금감원은 등록 없이 자동매매 프로그램을 판 업체를 미등록 투자일임으로 적발함(1절 출처).

**판매 전에 할 일**
1. **판매판에서는 키움 계좌 기능을 뺀다**(코드에서 판매판 빌드 때 계좌 칸·`account.js` 계좌 부분 제외). 가족판에만 남김.
2. 중계 서버는 판매판 주소를 허용 목록에 넣지 않는다.

**막히면 대안**: 사용자 계좌 연동이 꼭 필요하면 증권사 제휴(공식 계약) 또는 마이데이터 사업자 경로 — 규제·비용이 커서 지금 규모에서는 권하지 않음.

**결론: 고쳐서 진행(판매판에서 제외)**

## 4. 광고·화면 표시 (백테스트·수익률·안내 문구)

**지금 상태**
- 화면 일부에 '매수·매도 권유가 아니에요', '청약 점수(참고용)', '목표주가는 참고용' 있음. 전체 공통 '투자 참고용·원금손실' 안내는 README에만 있고 화면 하단에는 없음.
- 조건 검색에 **'신호 뒤 최고점 상승률'**(신호 다음 날부터 장중 최고가 ÷ 신호 날 종가)을 보여줌 → 실제로 그 값에 팔 수 없는 **미실현·최고점 기준 수익률**.
- 백테스트 스크립트·결과는 화면에 없음(내부용). README에 '상장폐지 종목이 빠져 결과가 좋게 나올 수 있음' 한계 적어 둠.
- 화면 하단에 **가족 4명 실명**이 공개 페이지에 노출돼 있음(가족판 문제이기도 함).

**확인한 사실**
- 유사투자자문업 광고 금지·필수 고지는 1절 참고(§101의2②, §101의3, 시행령 §102의2 — 금감원 매뉴얼). 특히 **실현되지 않은 수익률, 좋은 기간만 보여주기, 이익 난 종목만 골라 보이기** 금지.

**판매 전에 할 일**
1. '최고점 상승률'은 판매판에서 빼거나, 종가 기준 실제 수익률(+하락도 함께, 전체 기간 평균)로 바꾸고 '과거 결과는 미래를 보장하지 않음'을 붙임.
2. 백테스트·적중률을 홍보에 쓰지 않는다(쓰려면 전체 기간·비용·생존편향 포함, ⚖ 확인 후).
3. 모든 화면 하단 공통 고지: 1절 5번 문안(§101의3 세 가지) + 신고번호 + 시세 지연 가능 + 자료 출처.
4. '추천', '급등 예상', '수익 보장' 같은 말은 화면·홍보 어디에도 쓰지 않는다(회사 홍보 원칙과 같음).
5. 가족 실명 문구는 **판매판 시안에서 뺌**(11/26 김실장 전달). 가족판 노출은 그대로 두되 줄이는 쪽 권함(젠틀맨 결정).

**결론: 고쳐서 진행** (문구 최종본은 변호사 검토 때 함께)

## 6. 홍보 통로와 수익 구조 (계획, 11/26 김실장 전달)

**홍보 첫 통로: 젠틀맨 유튜브 '주식공무원 공식채널 주공tv' + 텔레그램 채널**
- 김실장 전달 사실: 구독 6.1천, 영상 2.5천 개, 마지막 업로드 2025-08-04, 텔레그램 채널 있음. 판매판 홍보의 첫 통로로 씀.
- 지킬 것:
  - 올리는 것(영상·글·고정 댓글·텔레그램 글)은 **건마다 젠틀맨 허락**.
  - 서비스를 알리는 영상·글은 표시·광고라서 **§101의3 고지 3가지 + 신고번호**를 넣음(설명란·고정 댓글·텔레그램 글 끝, 영상 안 자막도 권함).
  - 수익률·적중 자랑, '급등 종목', '수익 보장', 이익 난 종목만 골라 보여주기는 금지(1절). 점수 화면을 보여줄 때는 '계산 결과'로만 소개.
  - **유료 구독자와 양방향 소통 금지**: 유료 고객 전용 텔레그램은 '채팅 불가 채널(단방향)'로만 운영(금융위 보도자료가 든 단방향 예: 채팅 입력이 불가능한 채팅방, 푸시·알림톡). 유튜브 댓글에서 개별 종목 질문에 답하지 않음(1:1 투자자문 위험).
  - 회사 홍보 원칙도 그대로 지킴(사실만, 지어낸 후기 금지, '유일·최고' 금지, 광고비 0원).
- 디자인 시안 때 채널 분위기(색·로고·말투)와 어울리는지 함께 봄.

**수익 구조 후보 (결정 전, 후보로만)**
- 후보 A: 월 구독.
- 후보 B: 데시(dhesy.com) 방식 — '광고를 보면 1시간 무료 + 월 구독'. 젠틀맨이 본 구조. 넣을지 아직 결정 전.
  - B를 고를 때 확인할 것: 광고를 본 대가로 쓰는 무료 시간도 유사투자자문업의 '대가'로 보는지, 광고 화면에도 §101의3 고지가 필요한지 ⚖(변호사 질문지 17번). 광고 네트워크 약관(금융·투자 콘텐츠 제한), 개인정보(광고 식별자) 고지. 거래소 자료 계약이 '광고 수익'을 허용하는지(2절 ②는 '방문·가입으로 간접 수익'을 허용 목적으로 적고 있음, 확인 필요).
