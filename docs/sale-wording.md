# 판매판 문구 바꾸기 안 + C안 방향 (2026-11-26, 메이커)

원칙: 판매판 화면은 **사실과 계산 결과만** 말한다. 매매 시점·좋고 나쁨을 말하는 낱말, 우리 신호의 과거 성적 자랑은 뺀다(유사투자자문업 §101의2 — 단정적 판단·좋은 기간만·실현 안 된 수익률 금지, `sale-check.md` 1절).
코드는 아직 안 바꿈. 젠틀맨이 시안을 정한 뒤 판매판에서만 적용한다(가족판 문구는 그대로 둘 수 있음).

## 1. 바꿀 문구

| 곳 | 지금 | 판매판 안 |

## 2. C안 방향 메모 (첫 화면 구성·카드 배치까지 바꾸는 안, 3줄)
1. **첫 화면을 '오늘의 한 장'으로**: 시장 상태(사실 한 줄) → 점수 상위 5개 요약 카드 → 조건 검색 건수 → 전체 보기 단추 순으로, 지금의 지표 8칸은 접어서 한 줄 띠로.
2. **탭 10개를 폰 하단 탭바 5칸으로 묶기**(오늘 · 순위 · 조건 · 테마/공모 · 내 목록), 종목 상세는 전체 화면 시트로 '점수 근거 → 차트 → 수급 → 재무' 순서.
3. **브랜드 한 벌 새로**(주공tv와 맞춘 이름·로고·색), 모든 화면 하단 고지 고정, 무료/구독 경계와 '광고 보면 1시간 무료'(후보 B)가 들어갈 자리를 처음부터 잡아 둠.
